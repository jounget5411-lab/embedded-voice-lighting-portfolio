# 시연 영상 안내

[전체 시연](../media/demo.mp4)

영상의 표본 프레임과 화면 캡션을 기준으로 찾기 쉬운 구간을 정리했습니다. 통신 상태는 화면의 장애·복구 캡션과 LED 반응을 함께 읽습니다.

| 약 시작 시각 | 관찰할 장면 |
|---|---|
| 00:00–00:11 | 조명 색 변화와 초음파 근접 조건을 보여주는 장면 |
| 00:15.7 | SPI 장애를 표시하는 캡션 |
| 00:20.4 | UART 재연결을 표시하는 캡션 |
| 00:25.1 | SPI 복구와 UART 장애를 표시하는 장면 |
| 00:39.1 | 두 통신 경로의 장애 조건에서 입력에 반응하지 않는 장면 |

구간의 caption은 당시 시연 조건을 설명합니다. 모든 바이트의 무결성·장시간 운용 시험을 이 영상 하나로 입증하는 것으로 해석하지 않습니다. 단선 시험의 횟수·조건은 [결과 문서](results.md)에 구분했습니다.

# 시스템 구조

## 보드 사이의 경계

| 구성 | 입력 | 처리 | 출력 |
|---|---|---|---|
| A보드 | MAX4466 마이크 ADC | 8 kHz 취득, 160샘플 프레임, 필터·정수 특징 | 8바이트 특징을 포함한 패킷 |
| B보드 | SPI/UART 패킷, 초음파 Echo | 패킷 검증, 3프레임 누적, 분류·후처리, 거리 측정 | RGB LED의 색조·밝기 |
| PC | 음성/보드 특징과 라벨 | 특징 분석, 선형 모델 학습, 정규화·양자화 | 가중치 헤더 |

A보드의 ISR에서 긴 DSP를 실행하지 않고, 이중 버퍼로 완성된 프레임을 메인 루프에 넘깁니다. B보드에서는 전송 경로와 관계없이 같은 특징 표현을 받아 추론합니다.

## MCU의 연산 구성

160샘플마다 HPF, RMS, Vpp, ZCR와 Goertzel 다섯 성분을 계산합니다. A의 선택 코드에 기록된 주파수 순서는 `{1100,1200,2200,800,2300}`입니다. 이는 집합뿐 아니라 **배열 순서도 모델 입력의 일부**라는 점이 중요합니다.

8개 특징 × 3프레임을 24차원 입력으로 만들고, 정수 평균/스케일·가중치·편향으로 다섯 클래스 점수를 계산합니다. Warm/Cool/Low/High/Silence의 출력은 별도 안정화 조건을 거쳐 LED 명령으로 해석됩니다.

## 통신과 출력의 조건

- SPI를 먼저 사용하고 연속 실패 시 UART로 전환하는 구조입니다.
- STX·SEQ·LEN·payload·XOR·ETX 형식을 두 링크에서 공통으로 사용합니다.
- 정상 SPI가 다시 가능한지 일정 간격으로 확인합니다.
- 잘못된 패킷과 무음/불안정한 분류를 출력 명령으로 그대로 실행하지 않습니다.
- HC-SR04 Echo는 B보드 Timer1 입력 캡처로 측정합니다. 근접 조건과 분류 조건을 함께 만족할 때 RGB 상태를 바꿉니다.

초음파 측정에 Timer1을 사용하고 RGB PWM은 다른 타이머의 출력과 연결합니다. 포트·타이머 레지스터 설정은 공개한 원본 sketch에 남겼습니다.

## 후처리

무음 gate, 다수결, 연속 클래스 확인, 약 1초 불응기는 단발성 분류 결과가 LED 명령으로 반복 반영되는 것을 줄이는 구조입니다. 이 조건을 통과하는 시간은 프레임당 추론 시간보다 길 수 있으므로 두 수치를 분리합니다.

## 출처

시도7 A/B sketch, `weights_wclh_k5.h`, 프로젝트1 보고서 pp15–26·36–55와 상세 기술 기록을 기준으로 정리했습니다. 핀맵은 선택 코드와 실배선의 일치를 재확인한 뒤 업로드해야 합니다.

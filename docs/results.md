# 결과와 시험 조건

보고서와 시연 자료에 기록된 결과를 정리했습니다. 현재 저장소 코드로 장치를 재실행해 얻은 새 측정값은 아닙니다.

| 항목 | 보고서 기록 | 조건과 해석 |
|---|---|---|
| A보드 프레임 처리 | 평균 약 5.3 ms, 최대 약 6.3 ms | 20 ms 프레임의 DSP 구간. 전체 명령 반영 지연 아님 |
| B보드 정상 경로 처리 | 평균 약 310 µs, 최대 약 405 µs | 보고서의 GPIO/오실로스코프 구간 측정. 동일 공개 코드의 새 측정 아님 |
| 분류 평가 | accuracy 85.45%, macro F1 약 85.67% | 보고서의 평가값. 원 데이터 분할·최종 가중치와의 대응은 재검증하지 않음 |
| 연속 통신 시험 | 30,000프레임에서 SPI 실패 3회 | 서로 떨어진 실패로 기록되어 자연 시험 중 UART 전환은 0회 |
| 단선/복구 | 의도적 SPI 단선, UART 단선, 복구 및 이중 단선 조건 시험 | UART 폴백 근거는 의도적인 장애 시험과 구분해 읽어야 함 |

## 시연에서 보는 기능

음성 클래스에 따른 RGB 색조·밝기 변화와 근접 조건을 확인하는 영상입니다. [시연영상](../media/demo.mp4)에서 장치의 출력과 입력 조건을 함께 볼 수 있으며, 주요 장면의 위치는 [시연 구간 안내](demo.md)에 정리했습니다.

## 결과를 읽을 때의 범위

- 30,000프레임은 50 fps 기준으로 10분이지만 보고서에는 5분/10분 표기가 섞여 있습니다. 횟수를 중심으로 적었습니다.
- 3회 연속 실패 조건과 자연 시험에서 총 3회 실패한 사실은 같은 의미가 아닙니다.
- 작은 평가 데이터에서 나온 분류 수치를 수술실 현장 인식률로 확대하지 않습니다.
- LED 시제품을 의료용 조명 장치의 인증·안전 검증 결과로 소개하지 않습니다.
